# VEC-IoT MASAC Project

Complete repository package containing:

- VEC simulation environment and MASAC implementation
- Training, evaluation, and diagnostic scripts
- Colab notebook
- English LaTeX project report and compiled PDF

## Main execution files

- `train_masac.py` - training pipeline
- `evaluate_masac.py` - evaluation pipeline
- `run_phase3.py` - complete execution chain
- `diagnose_network.py` - model/system validation

## Report

The full English report is available in `latex_report/main.pdf`.
The LaTeX source is available in the same folder.
